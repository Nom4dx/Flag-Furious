# Test e fixture
Le fixture versionate includono ZIP ZipCrypto, 7z cifrato, JPEG Steghide e wordlist con candidati errati, corretti, Unicode, spazi e duplicati. I test coprono password nota, ricerca streaming, limite tentativi, vault, mascheramento persistente, XOR, CRC ZIP, 7z, Steghide, path traversal/symlink, discovery indipendente dalla cwd, mount sandbox read-only, manifest di integrazione, UI checkbox/conferma e scroll stabile. PDF/Office/ZIP AES vengono esercitati quando le dipendenze opzionali sono presenti; l'assenza produce `tool_missing`, non un falso fallimento globale.
