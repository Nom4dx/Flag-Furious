# Tool esterni
Tutti opzionali. Gli adapter registrano disponibilità, argv, exit code, stdout/stderr limitati e durata; non usano shell. `stegseek` è il nome corretto. Password solo se fornita dall'utente; nessun brute force automatico. I fallback interni garantiscono identificazione, carving, Unicode, LSB PCM/pixel e decoder anche senza binari.
