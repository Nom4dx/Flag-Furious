# Casi di test

Le fixture coprono magic JPEG/PNG/PDF/OLE/RTF/ZIP, JPEG comment/EXIF, XMP, IPTC,
PNG text, PDF Info/white text/revisioni/trailing data/azioni/stream, DOCX custom
properties/commenti/revisioni, XLSX hidden sheet, PPTX hidden slide, OLE fallback,
RTF hidden text, Base64/hex/Brainfuck, date discordanti, zero-width e polyglot.
I test non eseguono il contenuto e controllano offset, classificazione e JSON.
