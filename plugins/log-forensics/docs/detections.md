# Detection

Le detection individuali richiedono pattern con contesto di comando o richiesta.
Brute force, spraying, scan e beaconing richiedono aggregazione. Ogni finding ha
ID, severità, confidenza, eventi, sorgenti ed evidenza. Le anomalie descrivono una
deviazione dalla sola baseline disponibile e restano separate. Attack chain
mappa detection ordinate su fasi, senza dichiarare causalità certa.
