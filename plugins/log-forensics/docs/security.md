# Sicurezza e privacy

Input read-only, rete disabilitata, subprocess senza shell, timeout e output
bounded. Archivi bloccano traversal, symlink ed espansione anomala. Eventi UI
mascherano secret/token/password/cookie; nessun valore viene inviato fuori. I
payload estratti sono dati passivi e non vengono eseguiti. Cleanup è affidato al
workspace isolato del Forensic Hub.
